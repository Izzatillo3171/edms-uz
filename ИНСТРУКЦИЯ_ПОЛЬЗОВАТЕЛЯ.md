## Общая информация

Система электронного документооборота (СЭД) предназначена для автоматизации процессов работы с документами в государственных учреждениях Узбекистана. Система позволяет:

- Регистрировать входящие, исходящие и внутренние документы
- Принимать и обрабатывать обращения граждан
- Создавать резолюции и контролировать их исполнение
- Отслеживать статусы документов
- Формировать отчеты и статистику

### Типы пользователей

В системе существует 5 типов пользователей:

1. **Гражданин** - может подавать обращения и отслеживать их статус
2. **Секретарь** - регистрирует входящие и исходящие документы
3. **Руководитель** - создает резолюции, назначает исполнителей, подписывает документы
4. **Исполнитель** - выполняет назначенные задачи и отчитывается о проделанной работе
5. **Администратор** - управляет пользователями и отделами системы

## Вход в систему

### Первый вход

1. Откройте браузер и перейдите по адресу системы: `http://127.0.0.1:8000/`
2. На главной странице нажмите кнопку **"Войти"**
3. Введите ваш **логин** и **пароль**, предоставленные администратором
4. Нажмите кнопку **"Войти"**

### Регистрация нового пользователя (только для граждан)

1. На странице входа нажмите ссылку **"Зарегистрироваться"**
2. Заполните форму регистрации:
   - Логин (уникальное имя пользователя)
   - Email
   - Пароль (минимум 8 символов)
   - Повторите пароль
   - ФИО
   - Телефон (опционально)
3. Нажмите кнопку **"Зарегистрироваться"**
4. После успешной регистрации войдите в систему с вашими учетными данными

### Восстановление пароля

Если вы забыли пароль, обратитесь к администратору системы для его восстановления.

## Инструкции для граждан

### Подача обращения

#### Шаг 1: Переход к форме обращения

1. После входа в систему перейдите в раздел **"Подать обращение"** в боковом меню
2. Или перейдите напрямую по адресу: `http://127.0.0.1:8000/appeal/`

#### Шаг 2: Заполнение формы

1. **Тема обращения** - кратко опишите суть вашего вопроса (обязательно)
2. **Содержание** - подробно изложите ваше обращение (обязательно)
3. **Ваше ФИО** - укажите полное имя (обязательно)
4. **Государственное учреждение** - укажите, в какое ведомство направляется обращение
5. **Отдел-получатель** - выберите из списка соответствующий отдел (обязательно)
6. **Ответственное лицо** - выберите конкретного сотрудника для обработки (обязательно)

#### Шаг 3: Отправка обращения

1. Проверьте правильность заполненных данных
2. Нажмите кнопку **"Отправить обращение"**
3. После успешной отправки вы увидите **регистрационный номер** вашего обращения (например, `APP-20260502-0001`)
4. **Сохраните этот номер** - он понадобится для отслеживания статуса

### Отслеживание статуса обращения

#### Способ 1: Через личный кабинет

1. Войдите в систему под своим логином
2. На главной странице вы увидите раздел **"Мои обращения"**
3. Список показывает все ваши обращения с их статусами

#### Способ 2: По регистрационному номеру (без входа в систему)

1. Перейдите по адресу: `http://127.0.0.1:8000/status/`
2. Введите **регистрационный номер** вашего обращения
3. Нажмите кнопку **"Проверить статус"**
4. Система отобразит текущее состояние вашего обращения

### Расшифровка статусов обращений

- **Зарегистрирован** - обращение принято в систему и ожидает обработки
- **В работе** - обращение находится на рассмотрении у ответственного лица
- **Выполнен** - по вашему обращению принято решение, ответ готов
- **Просрочен** - превышен срок рассмотрения (15 дней по умолчанию)

### Просмотр деталей обращения

1. Нажмите на обращение в списке
2. Вы увидите:
   - Полную информацию об обращении
   - Статус обработки
   - Назначенного исполнителя
   - История изменений
   - Ответ на обращение (если готов)

## Инструкции для секретарей

### Основные функции секретаря

- Регистрация входящих документов
- Регистрация исходящих документов
- Просмотр списка всех документов
- Прием и отклонение входящих документов

### Регистрация входящего документа

#### Шаг 1: Переход к форме регистрации

1. В боковом меню выберите **"Регистрация входящих"**
2. Или перейдите по адресу: `http://127.0.0.1:8000/documents/incoming/register/`

#### Шаг 2: Заполнение данных документа

1. **Название документа** - краткое описание документа (обязательно)
2. **Содержание** - основной текст или краткое изложение
3. **Файл** - прикрепите скан-копию документа (если есть)
4. **Организация-отправитель** - укажите полное название отправителя
5. **ФИО отправителя** - контактное лицо

#### Шаг 3: Регистрация

1. Нажмите кнопку **"Зарегистрировать"**
2. Система автоматически присвоит документу уникальный номер вида `IN-20260502-0001`
3. Документ появится в общем списке со статусом **"Зарегистрирован"**

### Работа со списком документов

#### Просмотр списка

1. В боковом меню выберите **"Документы"**
2. Вы увидите список всех документов с основной информацией:
   - Регистрационный номер
   - Название
   - Тип документа
   - Текущий статус
   - Дата создания

#### Фильтрация документов

Используйте фильтры для поиска нужных документов:

1. **Поиск** - введите номер или название документа
2. **Тип документа** - выберите:
   - Входящий
   - Исходящий
   - Внутренний
   - Обращение гражданина
3. **Статус** - фильтр по текущему статусу
4. **Дата с/по** - укажите диапазон дат
5. Нажмите **"Искать"** или используйте кнопку **"Сбросить"** для очистки фильтров

### Прием и отклонение входящих документов

#### Просмотр документа на приеме

1. Откройте документ из списка (со статусом **"В ожидании"**)
2. Изучите содержание документа
3. Внизу страницы вы увидите две кнопки: **"Принять документ"** и **"Отклонить документ"**

#### Принятие документа

1. Нажмите кнопку **"Принять документ"**
2. Подтвердите действие
3. Документ получит статус **"Принято"**
4. В истории отобразится запись о приеме с вашим именем и датой

#### Отклонение документа

1. Нажмите кнопку **"Отклонить документ"**
2. В открывшейся форме укажите **причину отклонения** (обязательно)
3. Нажмите **"Отклонить"**
4. Документ получит статус **"Отклонено"**

### Экспорт документов

#### Экспорт в Excel

1. На странице списка документов нажмите кнопку **"Экспорт в Excel"**
2. Система сформирует файл Excel со всеми документами из списка
3. Файл автоматически загрузится в вашу папку загрузок

Экспортированный файл содержит:
- Порядковый номер
- Регистрационный номер
- Название документа
- Тип и статус
- Автора и срок исполнения
- Даты создания

## Инструкции для руководителей

### Основные функции руководителя

- Просмотр всех документов и статистики
- Создание резолюций
- Назначение исполнителей
- Подписание документов ЭЦП
- Контроль сроков исполнения

### Работа с панелью управления

После входа в систему вы видите панель управления с ключевыми показателями:

#### Карточки статистики

1. **Просрочено** (красная) - документы с истекшим сроком исполнения
2. **В работе** (желтая) - документы, находящиеся в процессе выполнения
3. **На резолюции** (синяя) - документы, ожидающие резолюцию
4. **Выполнено** (зеленая) - завершенные документы

#### Статистика по типам документов

- Входящие
- Исходящие
- Внутренние
- Обращения граждан

#### Последние документы

Список из 10 последних документов с быстрым доступом к ним.

### Создание резолюции

#### Шаг 1: Открытие документа

1. Перейдите в раздел **"Документы"** или **"Резолюции"**
2. Выберите документ, требующий резолюции
3. Откройте детальную страницу документа

#### Шаг 2: Создание резолюции

1. На странице документа нажмите кнопку **"Создать резолюцию"** (в правой колонке "Действия")
2. Откроется форма создания резолюции

#### Шаг 3: Заполнение резолюции

1. **Исполнитель** - выберите сотрудника из списка (обязательно)
   - Список содержит только пользователей с ролью "Исполнитель"
2. **Текст резолюции** - укажите поручение исполнителю (обязательно)
   - Например: "Прошу рассмотреть и подготовить ответ"
3. **Срок исполнения** - выберите дату (обязательно)
   - Рекомендуется устанавливать реальные сроки с учетом сложности задачи

#### Шаг 4: Сохранение резолюции

1. Нажмите кнопку **"Создать резолюцию"**
2. Система автоматически:
   - Изменит статус документа на **"В работе"**
   - Назначит исполнителя
   - Отправит уведомление исполнителю
   - Создаст запись в истории документа

### Подписание резолюции ЭЦП

#### Что такое ЭЦП в системе

ЭЦП (электронная цифровая подпись) используется для подтверждения резолюций и придания им юридической силы.

**Примечание:** В текущей версии используется упрощенная симуляция ЭЦП. Для работы с реальной ЭЦП необходима дополнительная настройка.

#### Процесс подписания

1. Откройте документ с созданной резолюцией
2. В разделе **"Резолюции"** найдите нужную резолюцию
3. Нажмите кнопку **"Подписать ЭЦП"** (если доступна)
4. На странице подписания:
   - Проверьте текст резолюции
   - Убедитесь в правильности исполнителя и срока
5. Установите галочку **"Я подтверждаю подписание"**
6. Нажмите кнопку **"Подписать"**
7. Система зафиксирует:
   - Подпись (ваше имя)
   - Дату и время подписания
   - Данные подписи

### Контроль исполнения

#### Просмотр задач исполнителей

1. На главной панели вы видите общее количество документов по статусам
2. Документы со статусом **"Просрочен"** выделяются красным цветом
3. Для детального просмотра:
   - Перейдите в раздел **"Документы"**
   - Используйте фильтр по статусу **"В работе"** или **"Просрочен"**

#### Работа с просроченными документами

1. Просроченные документы отображаются с иконкой предупреждения ⚠️
2. Вы можете:
   - Открыть документ и проверить причину задержки
   - Связаться с исполнителем
   - Продлить срок, создав новую резолюцию
   - Переназначить другому исполнителю

### Просмотр отчетов исполнителей

1. Откройте документ со статусом **"Выполнен"**
2. В разделе **"Резолюции"** найдите выполненную резолюцию
3. Отчет исполнителя отображается в поле **"Отчет"**
4. Проверьте качество выполнения задачи

## Инструкции для исполнителей

### Основные функции исполнителя

- Просмотр назначенных задач
- Работа с резолюциями
- Загрузка отчетов о выполнении
- Отслеживание дедлайнов

### Просмотр назначенных задач

#### Главная панель

После входа в систему вы увидите:

1. **Мои задачи** - общее количество назначенных вам документов
2. **В работе** - задачи, требующие выполнения
3. **Просрочено** - задачи с истекшим сроком (выделены красным)

#### Список задач

1. В боковом меню выберите **"Мои задачи"**
2. Вы увидите список всех документов, назначенных вам
3. Каждый документ содержит:
   - Регистрационный номер
   - Название документа
   - Текст резолюции
   - Срок исполнения
   - Текущий статус

### Работа с документом

#### Открытие задачи

1. Нажмите на документ в списке задач
2. Изучите:
   - Содержание документа
   - Текст резолюции руководителя
   - Срок исполнения
   - Прикрепленные файлы (если есть)

#### Понимание резолюции

1. В разделе **"Резолюции"** найдите резолюцию, назначенную вам
2. Обратите внимание на:
   - **Текст резолюции** - что именно нужно сделать
   - **Автор** - кто дал поручение
   - **Срок** - до какой даты необходимо выполнить
   - **Подпись** - подписана ли резолюция ЭЦП

### Выполнение задачи

#### Шаг 1: Подготовка отчета

1. Выполните поручение согласно резолюции
2. Подготовьте отчет о проделанной работе
3. Соберите необходимые документы или материалы

#### Шаг 2: Отчет в системе

1. На странице документа найдите кнопку **"Выполнить задачу"** в разделе "Действия"
2. Откроется форма для завершения резолюции

#### Шаг 3: Заполнение отчета

1. В поле **"Отчет о выполнении"** введите:
   - Что было сделано
   - Какие результаты достигнуты
   - Какие документы подготовлены
   - Рекомендации (если требуется)
2. Будьте конкретны и информативны

#### Шаг 4: Завершение

1. Нажмите кнопку **"Завершить задачу"**
2. Система автоматически:
   - Изменит статус документа на **"Выполнен"**
   - Зафиксирует дату и время завершения
   - Отправит уведомление руководителю
   - Создаст запись в истории

### Управление дедлайнами

#### Отслеживание сроков

1. На главной панели всегда видны задачи с приближающимися сроками
2. Просроченные задачи выделяются красным цветом и помечаются значком ⚠️
3. Система отправляет уведомления о приближении дедлайна

#### Если не успеваете в срок

1. **Заранее** свяжитесь с руководителем, давшим поручение
2. Объясните причину задержки
3. Согласуйте новый срок
4. Руководитель может создать новую резолюцию с продленным сроком

### Работа с уведомлениями

1. В боковом меню выберите **"Уведомления"**
2. Вы увидите все уведомления:
   - О новых назначениях
   - О приближении дедлайнов
   - О просроченных задачах
3. Нажмите на уведомление, чтобы перейти к документу
4. Прочитанные уведомления помечаются автоматически

## Инструкции для администраторов

### Основные функции администратора

- Управление пользователями
- Управление отделами
- Просмотр логов аудита
- Общее администрирование системы
- Доступ ко всем функциям системы

### Управление пользователями

#### Просмотр списка пользователей

1. В боковом меню выберите **"Пользователи"**
2. Вы увидите таблицу всех зарегистрированных пользователей:
   - Логин
   - ФИО
   - Email
   - Роль
   - Отдел
   - Статус (активен/неактивен)

#### Создание нового пользователя

1. На странице списка пользователей нажмите **"Создать пользователя"** (если кнопка доступна)
2. Или используйте страницу регистрации с правами администратора:
   - Перейдите на `/register/` будучи авторизованным как администратор
3. Заполните форму:
   - **Логин** - уникальное имя пользователя
   - **Email** - адрес электронной почты
   - **Пароль** - начальный пароль (минимум 8 символов)
   - **ФИО** - полное имя пользователя
   - **Роль** - выберите одну из:
     - Гражданин
     - Секретарь
     - Руководитель
     - Исполнитель
     - Администратор
   - **Отдел** - выберите отдел (для сотрудников)
   - **Телефон** - контактный номер
4. Нажмите **"Зарегистрировать"**
5. Сообщите новому пользователю его учетные данные

#### Редактирование пользователя

**Примечание:** В текущей версии редактирование пользователей доступно через Django Admin.

1. Перейдите в административную панель: `http://127.0.0.1:8000/admin/`
2. Войдите с правами суперпользователя
3. Выберите раздел **"Пользователи"**
4. Нажмите на нужного пользователя
5. Внесите необходимые изменения
6. Сохраните

#### Деактивация пользователя

1. В Django Admin откройте пользователя
2. Снимите галочку с поля **"Active"** (Активен)
3. Сохраните изменения
4. Пользователь не сможет войти в систему

## Часто задаваемые вопросы

### Общие вопросы

**В: Я забыл свой пароль. Что делать?**  
О: Обратитесь к администратору системы. Он сможет сбросить ваш пароль.

**В: Могу ли я изменить свою роль в системе?**  
О: Нет, роль может изменить только администратор системы.

**В: Как узнать, кто является администратором?**  
О: Обратитесь к руководству вашего отдела или учреждения.

**В: Система работает медленно. Что делать?**  
О: Обновите страницу (F5). Если проблема сохраняется, обратитесь в техническую поддержку.

**В: Можно ли работать с системой с мобильного телефона?**  
О: Да, интерфейс адаптирован для мобильных устройств, но рекомендуется использовать компьютер для полного функционала.

### Для граждан

**В: Сколько времени рассматривается обращение?**  
О: Стандартный срок рассмотрения - 15 дней с момента подачи. Конкретные сроки могут различаться.

**В: Могу ли я отозвать свое обращение?**  
О: Для отзыва обращения свяжитесь с ответственным лицом, указанным в вашем обращении.

**В: Как получить письменный ответ на обращение?**  
О: Ответ будет подготовлен ответственным лицом. Способ получения зависит от учреждения (электронно или по почте).

**В: Могу ли я подать несколько обращений?**  
О: Да, количество обращений не ограничено.

**В: Не могу найти нужный отдел в списке. Что делать?**  
О: Выберите наиболее подходящий отдел или обратитесь в канцелярию учреждения.

### Для секретарей

**В: Как изменить регистрационный номер документа?**  
О: Регистрационный номер присваивается автоматически и не может быть изменен. При ошибке необходимо удалить документ и создать новый.

**В: Могу ли я удалить документ?**  
О: Удаление документов доступно только администратору через Django Admin.

**В: Как прикрепить несколько файлов к документу?**  
О: В текущей версии можно прикрепить только один файл. Для нескольких файлов создайте архив (ZIP).

**В: Документ зарегистрирован с ошибкой. Как исправить?**  
О: Обратитесь к администратору для редактирования через Django Admin.

### Для руководителей

**В: Могу ли я переназначить резолюцию другому исполнителю?**  
О: Создайте новую резолюцию с новым исполнителем. Обе резолюции сохранятся в истории.

**В: Как отменить резолюцию?**  
О: Отмена резолюций напрямую не предусмотрена. Обратитесь к администратору.

**В: Исполнитель не может выполнить задачу. Что делать?**  
О: Создайте новую резолюцию с другим исполнителем или продлите срок.

**В: Как посмотреть все резолюции конкретного исполнителя?**  
О: Используйте фильтр по исполнителю на странице документов или обратитесь к администратору для формирования отчета.

### Для исполнителей

**В: Не могу найти свою задачу. Где она?**  
О: Проверьте раздел "Мои задачи" в боковом меню. Задачи также отображаются на главной панели.

**В: Могу ли я отказаться от задачи?**  
О: Задачи назначаются руководством. Для переназначения свяжитесь с руководителем, давшим поручение.

**В: Срок исполнения истек, но я не успел. Что делать?**  
О: Как можно скорее завершите задачу и отправьте отчет. Свяжитесь с руководителем для объяснения причин.

**В: Могу ли я редактировать отчет после отправки?**  
О: После завершения задачи редактирование недоступно. Обратитесь к администратору при необходимости.

### Для администраторов

**В: Как создать резервную копию системы?**  
О: См. раздел "Резервное копирование данных" в инструкциях для администраторов.

**В: Пользователь забыл пароль. Как сбросить?**  
О: В Django Admin откройте пользователя, нажмите ссылку "Reset password" и установите новый пароль.

**В: Как установить систему на production сервер?**  
О: Для production требуется:
   - PostgreSQL вместо SQLite
   - Настройка HTTPS
   - Настройка DEBUG=False
   - Использование gunicorn/uwsgi
   - Настройка nginx
   Обратитесь к документации Django.

**В: Как обновить систему до новой версии?**  
О: 
   1. Создайте резервную копию
   2. Обновите код из репозитория
   3. Выполните миграции: `python manage.py migrate`
   4. Перезапустите сервер

## Приложение: Глоссарий

**ЭЦП (Электронная цифровая подпись)** - криптографическая технология подтверждения подлинности электронного документа.

**Резолюция** - поручение руководителя исполнителю по конкретному документу.

**Регистрационный номер** - уникальный идентификатор документа в системе.

**Статус документа** - текущее состояние документа в процессе обработки.

**Исполнитель** - сотрудник, ответственный за выполнение поручения.

**Дедлайн** - срок исполнения задачи или резолюции.

**Аудит лог** - журнал всех действий пользователей в системе.

**Отдел** - структурное подразделение организации.

**Канцелярия** - служба документационного обеспечения управления.
