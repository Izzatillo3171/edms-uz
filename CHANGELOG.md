## 8. Известные ограничения

1. **Файлы**
   - Один файл на документ (можно использовать ZIP-архивы)
   - Нет предпросмотра файлов

2. **ЭЦП**
   - Упрощенная симуляция (не юридически значимая)
   - Требуется интеграция с реальным провайдером

3. **Редактирование**
   - Редактирование документов через Django Admin
   - Нельзя редактировать резолюцию после создания

4. **Уведомления**
   - Только внутрисистемные уведомления
   - Нет email/SMS

5. **База данных**
   - SQLite (для development)
   - Требуется PostgreSQL для production
